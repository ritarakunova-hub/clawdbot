# TAINA Content Reminder

Маленький сервис с одной задачей: каждый день в 9:00 по МСК проверяет
календарь постов и, если на сегодня что-то запланировано, присылает
вам в Telegram готовый текст (или тему, если текст ещё не написан) —
чтобы публикация не терялась и не требовала держать календарь в голове.

**Публикует не он — публикуете вы.** Бот только присылает текст,
вы сами копируете и вставляете в VK/Telegram/Instagram. Это осознанный
выбор: ваш голос работает именно потому, что это реально вы, а не
автоматика — тот же принцип human-in-the-loop, что в Sales Engine.

## Как это работает

1. Каждый день в 9:00 (МСК) сервис смотрит `data/posts.json` — есть ли
   запись на сегодняшнюю дату
2. Если есть готовый текст — шлёт его целиком, разворачивать и
   копировать не нужно
3. Если есть только тема (посты после 13.10 — расписаны только темы,
   без текста) — шлёт тему и напоминание про формулу «сцена →
   закономерность → тихое приглашение»
4. Если на сегодня ничего не запланировано — молчит, ничего не шлёт

## Что нужно от вас

**Ничего нового.** Использует тот же `TELEGRAM_BOT_TOKEN` и
`TELEGRAM_CHAT_ID`, что уже настроены для мини-CRM / Sales Engine —
отдельного бота заводить не нужно.

## Обновление календаря

Весь календарь — в `data/posts.json`, обычный текстовый файл. Чтобы
добавить/поменять пост:

- Найдите нужную дату (формат `"2026-10-15"`)
- Для готового текста: `"type": "full"` + поле `"text"`
- Для темы без текста: `"type": "topic"`, поле `text` не нужно

Когда будет время писать текст для темы из декабря — просто попросите
меня написать его, и я допишу прямо в этот файл.

## Деплой на Amvera

1. Создайте новое приложение на Amvera, подключите репозиторий, папка
   `content-reminder`
2. В **«Переменные и секреты»** добавьте (как секреты):
   - `TELEGRAM_BOT_TOKEN` — тот же, что в мини-CRM
   - `TELEGRAM_CHAT_ID` — тот же, что в мини-CRM
   - `TIMEZONE` (по умолчанию `Europe/Moscow`, можно не задавать)
   - `CRON_SCHEDULE` (по умолчанию `0 9 * * *` — каждый день в 9:00,
     можно не задавать)
3. `git push` в отслеживаемую ветку → Amvera соберёт и запустит

## Проверить прямо сейчас, не дожидаясь 9 утра

```
curl -X POST https://ВАШ-АДРЕС-НА-AMVERA/remind/now
```

Если зададите `REMINDER_SECRET` в переменных — добавьте
`?token=ВАШ_СЕКРЕТ` к адресу.

## Локальный запуск для проверки

```
cp .env.example .env
# заполните .env своими значениями
npm install
npm test      # проверка логики без реального Telegram
npm start     # http://localhost:3000
```
