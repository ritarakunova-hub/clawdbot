# TAINA Content Engine — V1

Генерация постов Claude → карточка-черновик в Telegram с кнопками →
ваше решение → публикация в Telegram-канал TAINA и (если настроен) в
VK. **Ничего никогда не публикуется без вашего клика «Опубликовать».**

Архитектура и принципы — те же, что в `../sales-engine`: один Node.js
сервис, Google Sheets как база/история, Telegram как пульт управления.

## Как это работает для вас день за днём

1. Открываете сайт сервиса → вводите тему поста, бриф (необязательно),
   отмечаете куда публиковать (Telegram / VK) → «Сгенерировать черновик»
2. Через несколько секунд в Telegram приходит карточка с готовым
   текстом и хэштегами
3. Под карточкой — кнопки **✅ Опубликовать / ❌ Отклонить / ✏️ Изменить**
4. **Опубликовать** — пост сразу уходит в выбранные платформы
5. **Изменить** — откройте таблицу, поправьте колонки `text`/`hashtags`
   у нужной строки (найдите по `id` — он есть в самом низу карточки,
   после `Куда:`), затем нажмите **✅ Опубликовать** на этой же карточке
   ещё раз — кнопки специально не пропадают после «Изменить», чтобы не
   пересоздавать черновик заново
6. **Отклонить** — пост остаётся в таблице со статусом «Отклонён»,
   никуда не публикуется

Все черновики (даже отклонённые) сохраняются в таблице — это ваша
история постов.

## Что нужно сделать вам (без этого не заработает)

### 1. Google-таблица

Создайте новую Google-таблицу (отдельную от mini-crm/sales-engine),
назовите лист `Посты`. Первая строка — заголовки для удобства:

```
id | topic | brief | text | hashtags | platforms | status | created_at | last_status_update | telegram_message_id | published_at | notes
```

Сервисный аккаунт Google можно переиспользовать тот же, что в
mini-crm/sales-engine (тот же `client_email`/base64-ключ) — просто
дайте ему доступ **Редактора** и к этой новой таблице тоже. Скопируйте
**ID таблицы** (из URL, между `/d/` и `/edit`).

### 2. Ключ Anthropic (Claude)

Можно использовать тот же `ANTHROPIC_API_KEY`, что в sales-engine —
это один и тот же аккаунт. Если ещё нет — [console.anthropic.com](https://console.anthropic.com) → **API Keys → Create Key**.

### 3. Telegram-бот и канал

Можно использовать того же бота, что в mini-crm/sales-engine, — но
для публикации в канал ему нужны **дополнительные права**:

1. `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` (личный чат для карточек)
   — как в mini-crm/README.md, разделы «Шаг 3»/«Этап 2», если ещё не
   настроено
2. **Канал TAINA**: откройте канал в Telegram → **Управление каналом →
   Администраторы → Добавить администратора** → добавьте вашего бота
   → дайте право «Публикация сообщений»
3. `TELEGRAM_CHANNEL_ID`: если канал публичный — просто `@имя_канала`
   (то, что после `t.me/`). Если приватный — числовой id, его проще
   всего получить, переслав любое сообщение из канала боту
   [@JsonDumpBot](https://t.me/JsonDumpBot) и посмотрев `chat.id` в
   ответе
4. `TELEGRAM_WEBHOOK_SECRET` — свой пароль для вебхука (как в
   sales-engine)

### 4. VK — необязательно

Если пока не нужен VK — просто не заполняйте `VK_ACCESS_TOKEN`/
`VK_GROUP_ID`, публикация в VK будет автоматически пропускаться (без
ошибок), заработает только Telegram-канал.

Когда будете готовы подключить VK:

1. Откройте сообщество VK → **Управление → Работа с API → Ключи
   доступа → Создать ключ** → отметьте право доступа **«Стена»** →
   это `VK_ACCESS_TOKEN`
2. `VK_GROUP_ID` — число из ссылки на сообщество (или
   **Управление → Настройки → ID сообщества**), без минуса

### 5. Деплой на Amvera

1. Создайте новое приложение на Amvera, подключите репозиторий, папка `content-engine`
2. В **«Переменные и секреты»** добавьте (как секреты):
   - `ANTHROPIC_API_KEY`
   - `GOOGLE_SHEET_ID`, `GOOGLE_SERVICE_ACCOUNT_KEY_BASE64`
   - `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `TELEGRAM_CHANNEL_ID`,
     `TELEGRAM_WEBHOOK_SECRET`
   - `VK_ACCESS_TOKEN`, `VK_GROUP_ID` — если решили подключить VK
   - `APP_USERNAME`, `APP_PASSWORD` — свои логин/пароль для формы
3. `git push` в отслеживаемую ветку → Amvera соберёт и запустит по `amvera.yml`
4. После деплоя Amvera покажет адрес, например `https://taina-content.amvera.io`

### 6. Подключить кнопки Telegram к сервису

```
curl "https://api.telegram.org/botВАШ_ТОКЕН/setWebhook?url=https://ВАШ-АДРЕС-НА-AMVERA/telegram/webhook&secret_token=ВАШ_TELEGRAM_WEBHOOK_SECRET"
```

⚠️ Если этот же бот уже используется в mini-crm/sales-engine с
вебхуком на другой адрес — `setWebhook` **перезапишет** его: у одного
бота может быть только один активный вебхук. Либо заводите отдельного
бота для контента (создать нового через @BotFather — 2 минуты), либо
держите в уме, что переключение вебхука между проектами придётся
делать вручную.

## Локальный запуск для проверки

```
cp .env.example .env
# заполните .env своими значениями
npm install
npm test      # проверка логики без реальных API
npm start     # http://localhost:3000
```

## Чего сознательно нет в V1 (следующие этапы)

- **Instagram** — нужен Business-аккаунт Instagram, привязанный к
  Facebook Page, и токен Meta Graph API; настройка сложнее (проверка
  приложения от Meta) — делаем отдельным этапом, когда решите, что
  Instagram нужен именно сейчас
- **Блог на сайте taina-site** — сайт статический (Netlify), поэтому
  публикация поста на сайт означает либо пересборку страницы при
  каждом посте, либо простую JS-подгрузку списка постов на отдельную
  страницу `/blog` с сервиса. Второй вариант проще и не ломает
  существующий дизайн — обсудим отдельно, когда будет готова эта часть
- Расписание автопубликации (сейчас только «одобрил → сразу
  опубликовано») — если понадобится публиковать по календарю без
  ручного клика, добавим `node-cron` аналогично follow-up в
  sales-engine
- Разный текст под разные платформы (сейчас один и тот же текст идёт
  и в Telegram, и в VK)

Архитектура (`src/claude.js`/`src/sheets.js`/`src/telegram.js`/`src/vk.js`)
сделана так, чтобы это можно было добавить позже, не переписывая всё
с нуля.
