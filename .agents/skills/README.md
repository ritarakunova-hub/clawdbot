# TAINA project skills

These are repository-local Codex skills. Codex can discover each skill from its `SKILL.md` when this repository is opened.

| Skill | Use for |
|---|---|
| `taina-product-strategy` | ICP, discovery, product positioning, roadmap, pricing experiments |
| `taina-growth-marketing` | Landing pages, SEO, YouTube, Telegram/VK content, launch experiments |
| `taina-sales-ops` | CRM, lead qualification, n8n, follow-up, Telegram, payments |
| `taina-product-quality` | Code review, security, tests, release readiness, deployment |

Load only the skills relevant to the current task. Always read the actual product code and project docs before acting. Skills guide execution; they do not authorize production deployment, spending money, sending messages, or changing live customer data.
