# Деплой на Netlify (Этап 15)

Что подготовлено в коде — сделано. Что требует вашего аккаунта, домена
и решений — список шагов ниже, по порядку. Ни один из этих шагов я
сама выполнить не могу (нужен доступ к вашему Netlify/домену/n8n).

## Что уже готово в коде

- `netlify.toml`: команда сборки (`npm run build`), папка публикации
  (`dist`), версия Node (22 — та же, что при разработке), заголовки:
  - `X-Robots-Tag: noindex` — сайт пока черновик, синхронизировано с
    `<meta name="robots">` в `Layout.astro`.
  - Базовые заголовки безопасности (`X-Content-Type-Options`,
    `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy`).
  - `Content-Security-Policy-Report-Only` — ничего не блокирует, только
    показывает нарушения в консоли браузера при ручной проверке.
    **Важно:** сейчас в отчётах будут упоминаться встроенные `<script>`
    на странице (калькулятор в «Демо», форма в «Контакте») — это
    ожидаемо для report-only режима, они не сломаются. Если решите
    когда-нибудь **включить** CSP по-настоящему (не report-only) —
    это отдельная небольшая задача (перенести эти скрипты во внешние
    файлы или настроить nonce), не делайте её просто по этому файлу.
  - Кэш: хешированные файлы (`/_astro/*`) — на год, HTML — без кэша,
    чтобы обновления сайта доходили сразу.
- `npm run build` — чистый, без ошибок и предупреждений (проверено
  только что).
- Форма — Netlify Forms, найдётся сканером при сборке сама (см.
  `docs/form-contract.md`), доп. настройка не нужна кроме шага 4 ниже.

## Шаги, которые нужны от вас

### 1. Подключить репозиторий
В Netlify: **Add new site → Import an existing project** → выбрать этот
GitHub-репозиторий, ветку `claude/inspiring-newton-wp3tq6` (или `main`,
если решите слить туда). Настройки сборки Netlify подхватит сам из
`netlify.toml` — менять ничего не нужно.

### 2. Домен и HTTPS
- Свой домен: **Site settings → Domain management → Add a domain** →
  следовать инструкции Netlify по DNS-записям у вашего регистратора
  домена. Либо временно использовать бесплатный поддомен вида
  `<name>.netlify.app`, который Netlify выдаёт сразу — им тоже можно
  пользоваться, пока не купите домен.
- HTTPS Netlify включает сам и бесплатно (Let's Encrypt), как только
  домен подключён — отдельно ничего настраивать не нужно.

### 3. Открыть индексацию (когда решите, не раньше)
Пока сайт черновик — оставьте `noindex` как есть. Когда решите, что
готовы показываться в поиске:
1. В `src/layouts/Layout.astro` убрать строку
   `<meta name="robots" content="noindex, nofollow" />`.
2. В `netlify.toml` убрать строку `X-Robots-Tag = "noindex"`.
3. Добавить `sitemap.xml` (см. `docs/seo.md`) — на этом шаге уже будет
   известен домен.
Скажите — я сделаю все три правки одним коммитом.

### 4. Уведомления формы → вебхук n8n
Когда будет готов адрес вебхука n8n:
**Site settings → Forms → Form notifications → Add notification →
Outgoing webhook** → вставить URL вебхука. Дальше форма `taina-diagnostic`
будет сама слать каждую заявку на этот адрес — код сайта менять не
нужно, это чисто настройка в интерфейсе Netlify.

### 5. Переменные окружения
Сейчас сайту не нужен ни один секрет (ключи, токены) — весь HTML
статический, формы обрабатывает сама Netlify. Если позже подключите
Яндекс.Метрику (см. `docs/seo.md`) — номер счётчика будет уместно
хранить как переменную окружения (**Site settings → Environment
variables**), не в коде.

## Ветки и preview-деплои

Netlify по умолчанию делает предпросмотр для каждого пул-реквеста и
отдельный билд для каждой ветки — ничего дополнительно настраивать не
нужно, `netlify.toml` уже общий для всех веток. Когда решите, какая
ветка «боевая» (обычно `main`), укажите это в **Site settings → Build &
deploy → Branches** как Production branch.

## Чек-лист запуска (пройти после первого деплоя)

- [ ] Сайт открывается по адресу `<name>.netlify.app` или вашему домену.
- [ ] Отправить тестовую заявку через форму — она должна появиться в
      **Site settings → Forms → taina-diagnostic** (в интерфейсе
      Netlify) сразу после отправки.
- [ ] Как только настроен шаг 4 (вебхук) — та же тестовая заявка должна
      дойти до n8n → попасть в Google-таблицу → прийти уведомление в
      Telegram (это уже вне зоны кода сайта, проверяется в n8n).
- [ ] Открыть сайт с телефона — все сцены, форма, демо-чат работают.
- [ ] Проверить 404: зайти на несуществующий адрес (например,
      `/несуществующая-страница`) — должна быть страница ошибки, не
      белый экран. *(Сейчас отдельной страницы 404 в проекте нет —
      Netlify покажет свою стандартную. Если нужна фирменная страница
      404 — скажите, сделаю за один шаг.)*
- [ ] `favicon.svg` виден во вкладке браузера.
- [ ] HTTPS работает (замочек в адресной строке), обычный `http://`
      сам перенаправляется на `https://` (Netlify делает это по
      умолчанию).
