# Релизный отчёт (Этап 16 — регресс и релиз)

Итог автономной работы: «Дострой сцены всё, что сам можешь». Что вошло,
что проверено, что осталось решить владелице — одним документом.

## Прогон всего, что есть

```
npm run build   — чисто, без ошибок и предупреждений
npm run check   — 66 файлов, 0 ошибок, 0 предупреждений, 0 подсказок
npm run lint    — чисто
npm run contrast — все 7 пар цветов проходят AA (≥4,5:1)
npx playwright test — 33/33 зелёных
```

Lighthouse на мобильном профиле не прогоняла целиком — эта сессия
работает в песочнице без настоящего GPU (WebGL2 через SwiftShader,
программный рендер), результат для 3D-метрик был бы нерепрезентативным.
Подробности и что уже измерено честно (вес бандлов, порядок загрузки) —
`docs/performance.md`.

## Что вошло в эту работу (после «Что осталось сделать?»)

1. **«Проявка»** — 3D-сцена проявления листа.
2. **«Три территории»** — скролл-скраб плёнка, раскрытие карточек на весь
   экран (FLIP), клавиатура и мобильная раскладка.
3. **Демо** — чат стал живым в mock-режиме, честные отказы вместо
   выдумывания, без вебхука.
4. **«Проект» и «Бегемот»** — хаос листов на GPU оседает в стеллаж; кот
   проявляется в темноте, ромб загорается в глазу.
5. **Пакеты** — наклон карточек, светлое пятно за курсором, нажатие.
6. **Форма заявки** — по образцу реально работающей `taina-diagnostic`
   (имя/контакт/сообщение), чекбокс согласия, честные заглушки политики
   и оферты, предзаполнение из выбранной территории/пакета, сохранение
   UTM.
7. **Ассеты** — аудит, OG-изображение из ромба и кота, портрет-заглушка.
8. **Доступность** — axe-core (0 нарушений на 6 состояниях), зоны нажатия
   ≥44px, клавиатура сквозь весь путь.
9. **Производительность** — отчёт по весу бандлов и порядку загрузки.
10. **SEO** — JSON-LD (без выдуманных оценок и отзывов), robots.txt,
    инструкция по Яндекс.Вебмастеру и Метрике.
11. **Netlify** — `netlify.toml` (заголовки безопасности, CSP report-only,
    кэш), пошаговая инструкция по деплою.

Каждый пункт — отдельный коммит в `claude/inspiring-newton-wp3tq6`, с
понятным сообщением по-русски и инструкцией «как проверить глазами».

## Что нужно проверить руками на реальных устройствах

Песочница подтверждает логику и вёрстку, но не заменяет реальный экран
и настоящий GPU:

- [ ] Один средний Android-телефон (не топовый) — плавность 3D-сцен,
      скорость демо-чата, удобство формы с виртуальной клавиатурой.
- [ ] Один iPhone — то же самое плюс проверка Safari-специфичных вещей
      (свайп-навигация, safe-area у шапки).
- [ ] Реальный Lighthouse-прогон на мобильном профиле после деплоя
      (Этап 15) — этой сессии в песочнице недоступен честно.

## Известные ограничения (не баги — сознательные решения)

- Тексты «Трёх территорий» и обрамление «Бегемота» — черновик
  `[НА УТВЕРЖДЕНИЕ]`, ждут вашей правки (`docs/content-comparison.md`).
- Отзыв клиента скрыт (`reviewApproved: false`) — не включала сама.
- Текст политики конфиденциальности и договора-оферты — честная
  заглушка «Текст будет добавлен», ждёт от вас (`docs/approve-texts.md`).
- Демо-чат отвечает по трём записанным сценариям (mock-режим) — станет
  живым чатом с реальным поиском, когда появится адрес вебхука n8n.
- Скорость дрейфа камеры «Хиро» в покое — по расчёту чуть выше бюджета
  0,03 ед/с из CLAUDE.md (см. `docs/accessibility.md`), не трогала без
  вашего решения — это часть поведения из согласованного эталона.
- Индексация в поиске выключена (`noindex`) — сознательно, сайт ещё
  черновик.
