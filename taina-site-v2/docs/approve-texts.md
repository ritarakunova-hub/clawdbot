# Тексты сайта на утверждение

Все тексты, которые сейчас есть на странице, собраны здесь по секциям —
простым языком, без вёрстки. Что я придумала — помечено
`[НА УТВЕРЖДЕНИЕ]`. Что подтверждено (цены, факты, отзыв) — помечено явно.
Ничего с пометкой `[НА УТВЕРЖДЕНИЕ]` не является выдуманным фактом о вашем
бизнесе — это черновая формулировка, которую надо либо одобрить, либо
попросить переписать.

**Обновлено.** Бо́льшая часть секций ниже (Проявка — частично, Демо,
Проект, Пакеты) теперь взята дословно из `docs/old-site-content.md`

— пометки `[НА УТВЕРЖДЕНИЕ]` с этих кусков сняты, они больше не черновик.
`[НА УТВЕРЖДЕНИЕ]` остаётся только там, где в утверждённом источнике
текста действительно нет (см. список в конце файла).
