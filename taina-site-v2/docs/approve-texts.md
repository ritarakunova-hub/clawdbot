# Тексты сайта на утверждение

Все тексты, которые сейчас есть на странице (Этап 2), собраны здесь по
секциям — простым языком, без вёрстки. Что я придумала — помечено
`[НА УТВЕРЖДЕНИЕ]`. Что подтверждено (цены, факты, отзыв) — помечено явно.
Ничего с пометкой `[НА УТВЕРЖДЕНИЕ]` не является выдуманным фактом о вашем
бизнесе — это черновая формулировка, которую надо either одобрить, either
попросить переписать.

Дважды в этом файле встречается фраза «не показывается на странице» — это
контент, который есть в коде (в `src/content/copy.ts`), но не выводится на
сайт, пока вы явно не разрешите.
