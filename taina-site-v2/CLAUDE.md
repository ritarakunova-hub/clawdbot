# TAINA STUDIO — сайт «Проявка»

Этот файл читай первым, в начале каждой сессии.

## Что строим
Иммерсивный сайт студии TAINA STUDIO: AI и автоматизация для сильного бизнеса + образы и смыслы.
**Одна главная цель — заявка на AI-аудит** (форма). Аудитория: руководители бизнеса, у которых повторяющиеся вопросы и разрозненные документы.
**Идея — «Проявка»:** тёмная комната, красный ромб — источник света, он проявляет смысл. Скрыто → проявилось, тьма → свет, хаос → порядок.
В `reference/taina-hero.html` лежит рабочий прототип первого экрана (Three.js, шейдеры). Это эталон вида и поведения.

## Как работать (обязательно)

3. Не ломай работающее. Не удаляй и не переписывай без причины. Если нужно — объясни, зачем.
4. Малые шаги, после каждого сборка. Один этап — одна ветка, понятные коммиты по-русски.
5. Не добавляй зависимости без причины и объясни выбор.
6. Я не разработчик. Объясняй простым языком, в конце каждого этапа пиши, **как проверить глазами** на компьютере и на телефоне.
7. Если что-то неясно, задай один вопрос и предложи вариант, не блокируйся.

## Стек
- Astro (статическая сборка) + TypeScript.
- Three.js из npm (ESM), **один canvas на весь сайт**, сцены — это состояния. Постобработка: EffectComposer + UnrealBloomPass + свой финальный проход (зерно, виньетка, тонмаппинг).
- CSS без фреймворков, дизайн-токены в CSS-переменных.
- Шрифты self-host через `@fontsource` (Cormorant Garamond как замена «Taina Serif», Inter; подмножества cyrillic и latin).
- Формы: Netlify Forms. Хостинг: Netlify. Заявки дальше идут в n8n → Google Sheets → Telegram (настраивается вне кода).
- Тесты: Playwright (скриншоты, поведение), axe-core (доступность), Lighthouse CI (бюджеты).

Команды: `npm run dev`, `build`, `preview`, `check` (astro check + tsc), `lint`, `test`, `lighthouse`.

## Бренд
Цвета: Deep Black `#0A0A0B` (фон), Charcoal `#1A1A1F` (поверхности), Stone `#3A3A3F` (линии), Antique Gold `#D4AF37` (акценты, кнопка), Ivory `#EDE8DB` (текст), Sand `#C9B99A` (второй текст), Ruby `#E22C34` и Crimson `#8F1D24` (ромб).
Пропорции: 80% чёрные, 12% Ivory/Sand, 6% золото, 2% красный. Красный только там, где происходит открытие. Crimson на чёрном даёт контраст около 2,2:1, поэтому он никогда не бывает текстом.
Шрифты: заголовки Cormorant Garamond 500, интерфейс и текст Inter. Слоган: «AI и автоматизация для сильного бизнеса». Строка бренда: «Технологии / Люди / Результат».
Символ: красный гранёный ромб. Маскот: чёрный кот, показывается только глазами, силуэтом, хвостом, каждый раз по-разному.
Свет: ключевой — красный ромб, заполняющий — тёплое золото, тени — глубокий чёрный.

## Движение (из документа «Система движения»)
Работа каждой анимации: ориентация, причина и следствие, смысл или внимание. Иначе её нет.
Easing: `out` = 1−(1−t)³, `inOut` = кубический in-out, `settle` = easeOutBack(1,4) только для входа ромба, `scrub` = линейный.
CSS-кривые: out `cubic-bezier(.215,.61,.355,1)`, inOut `cubic-bezier(.645,.045,.355,1)`.
Тайминги: отклик 90–320 мс, сцена 0,9–1,6 с, световой фронт по заголовку 2,3 с, мир (дрейф) 8–30 с.
Скролл нативный, без перехвата. Сглаживаются только значения прогресса: `k = 1 − 0.003^dt`.
Анимируем только `transform` и `opacity`. Без `filter: blur` на больших слоях, без анимации `box-shadow`, размеров и позиции. Раскрытие блоков через `grid-template-rows: 0fr → 1fr`.

## Бюджеты
LCP ≤ 2,5 с, INP ≤ 200 мс, CLS 0. Стартовый JS ≤ 250 КБ gzip, 3D-код и ассеты подгружаются лениво после первого экрана. 3D-ассеты ≤ 3–4 МБ, видеопетля ≤ 1,2 МБ. Кадр ≤ 16,6 мс, вызовов отрисовки ≤ 40, листов 180 на десктопе и 96 на телефоне.
Уровни: A полный, B телефон (без MSAA, облегчённый bloom), C reduced-motion или нет WebGL (статика), D без JS (обычная страница). Каждый уровень обязан работать.

## Тексты
Тон: умный, загадочный, уверенный, чуть дерзкий. Не корпоративный, не инфобизнес. Никаких слов «уникальный», «креативный», «эксклюзивный». Первое предложение — суть, без «Мы делаем AI!». Регистр предложений, без КАПСА в подписях. Кнопка называет действие: «Заказать AI-аудит», «Отправить заявку».
**Не выдумывай факты, цифры, кейсы, отзывы.** Если данных нет, поставь пометку `[НА УТВЕРЖДЕНИЕ]`.
