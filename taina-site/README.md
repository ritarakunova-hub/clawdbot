# TAINA Knowledge Map — product landing page

Статический сайт раннего доступа к приложению TAINA Knowledge Map.

## Файлы
- `index.html` — продуктовая страница, мобильная адаптация, Netlify Form.
- `thanks.html` — подтверждение отправки заявки.
- `LAUNCH-PLAN.md` — стратегия проверки спроса, воронка, метрики и минимальная автоматизация.
- `PERSONAL-DATA-COMPLIANCE.md` — внутренний release gate по 152-ФЗ; не является публичной политикой.

## Деплой
Сайт находится в репозитории `ritarakunova-hub/clawdbot`, каталог публикации — `taina-site`.

Для Netlify при подключении Git:
- Repository: `ritarakunova-hub/clawdbot`
- Branch: `feat/taina-knowledge-map-launch-site` для предпросмотра; после ревью — основная ветка
- Base directory: `taina-site`
- Build command: пусто
- Publish directory: `.` (относительно Base directory)

**Не менять production-настройки Netlify до проверки текущего сайта и публикационного каталога.** Ранее в контексте фигурировал `taina-site-v2`, которого нет в проверенной ветке репозитория. Сначала нужно сверить фактическую настройку сайта.

## Форма и персональные данные

**Сбор заявок сейчас отключён.** В текущем preview форма заменена информационным сообщением, поскольку оператор — физическое лицо на НПД, а применимость требований 152-ФЗ, локализация первичного хранения и география обработки Netlify Forms ещё не подтверждены.

До включения формы пройти `PERSONAL-DATA-COMPLIANCE.md`: определить фактического оператора, проверить уведомление Роскомнадзора и исключения, выбрать подходящую инфраструктуру в РФ, подготовить и опубликовать политику и отдельное согласие. Не отправлять реальные персональные данные через Netlify Forms, пока география и правовая схема не проверены.

После закрытия блокеров тестировать форму на тестовых данных и только затем подключать уведомления/webhook. Форма не должна обещать оплату, создание аккаунта или автоматическую выдачу приложения.

## Обязательные блокеры до публичного запуска
- Проверить и указать фактические реквизиты оператора персональных данных и опубликовать корректную политику обработки персональных данных/согласие. Сейчас требуется юридическая проверка текста формы и документации.
- Проверить Netlify Form на реальном домене.
- Подключить и проверить уведомления.
- Согласовать финальную цену и условия ранней лицензии.
- Закрыть release gate приложения из `taina-knowledge-map/RELEASE-CHECKLIST.md`.

## Честное описание V1
Приложение — local-first инструмент структурированной диагностики одного процесса. Нет аккаунтов, облачного хранения, синхронизации, совместного редактирования, встроенного AI и автоматического чтения файлов. Данные хранятся в IndexedDB браузера на устройстве пользователя. Для пилота использовать только синтетические или обезличенные сведения. Эти ограничения прямо раскрыты на продуктовой странице.
