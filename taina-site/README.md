# Сайт TAINA — production-версия

Готовый к деплою `index.html` — тот же дизайн, что в вашем Design-
канвасе, с одним исправлением: форма диагностики теперь настоящая
Netlify-форма (раньше была `mailto:` ссылка, заявки не попадали в
мини-CRM).

Проверено: HTML валиден, страница отрендерена в браузере (скриншоты
hero и формы), отправка формы не выдаёт JS-ошибок.

## Первый деплой на Netlify (у вас сайта ещё нигде нет — с нуля)

### Вариант А — самый простой, drag-and-drop (5 минут)

1. Зайдите на [app.netlify.com](https://app.netlify.com) → зарегистрируйтесь/войдите
2. На главной странице — область «Drag and drop your site output folder here»
3. Перетащите туда папку `taina-site` целиком (именно папку, не файл)
4. Netlify сразу опубликует сайт и даст временный адрес вида
   `random-name-123.netlify.app` — можно переименовать в настройках
   сайта (**Site settings → Change site name**)
5. Подключить свой домен — **Site settings → Domain management** (если
   домен уже есть)

Минус: при любом изменении сайта придётся заново перетаскивать папку
руками.

### Вариант Б — через Git, с автодеплоем (чуть дольше, удобнее на будущее)

1. На Netlify: **Add new site → Import an existing project → Deploy with GitHub**
2. Выберите репозиторий `ritarakunova-hub/clawdbot`, ветку
   `claude/greeting-fhvuma` (или основную, если вольёте туда)
3. **Base directory**: `taina-site`
4. **Build command**: оставить пустым (сайт статический, собирать
   нечего)
5. **Publish directory**: `taina-site` (или `.`, если Base directory
   уже указан — Netlify тогда публикует корень base directory)
6. Deploy — дальше любой `git push` в эту ветку/папку будет
   автоматически обновлять сайт

## Подключить заявки к мини-CRM (обязательный шаг после деплоя)

Форма уже готова технически (`data-netlify="true"` в HTML) — но чтобы
заявки реально попадали в вашу таблицу и Telegram, нужно один раз
включить Outgoing Webhook — это описано в
`../mini-crm/README.md`, раздел «Шаг 4. Подключить Netlify»:

1. Netlify → ваш сайт → **Site settings → Forms → Form notifications → Add notification → Outgoing webhook**
2. URL: `https://ВАШ-АДРЕС-НА-AMVERA/webhook/netlify-lead?token=ВАШ_WEBHOOK_SECRET`
3. Form: `taina-diagnostic` (имя формы уже прописано в HTML)

Без этого шага заявки будут просто накапливаться в разделе **Forms**
личного кабинета Netlify — тоже не потеряются, но без уведомлений и
без вашей таблицы.

## Проверка после деплоя

Откройте сайт → заполните форму → отправьте → должно появиться «Спасибо,
мы получили заявку». Затем проверьте:
1. Netlify → **Forms** → должна появиться запись `taina-diagnostic`
2. Если подключили вебхук — строка должна появиться в Google-таблице
   мини-CRM и прийти уведомление в Telegram
