# «Бегемот» — мини-сериал TAINA. Глава первая

Чёрный пушистый кот Бегемот, Петербург, дождь и дверь TAINA.
Три вертикальные серии (9:16) по 37–38 секунд для Reels, VK Клипов, Shorts.
Всё нарисовано кодом, звук синтезирован. Сюжетная рифма: у кота не было дома, и он даёт дом документам,
а потом помогает людям найти ответ. Это ядро бренда: «Ответ уже есть. TAINA помогает его найти».

## Серия 1 · «Дождь»

| Время | Что происходит |
|---|---|
| 0–6 | Ночной Петербург под дождём: Адмиралтейство, Исаакий, Петропавловка, Нева. Титр «Бегемот · Серия 1 · Дождь» |
| 6–10 | Бегемот бредёт по улице. У кофейни распахивается дверь, человек с метлой: **«Кыш!»** |
| 12–14 | Парадная №12: **«Нельзя!»** |
| 16–18 | Лавка гасит свет: **«Закрыто!»** |
| 19–22 | Кот останавливается под дождём, опускает голову. *Бегемот:* «Неужели в этом городе нет двери для меня?» |
| 22–24 | Впереди — красный отблеск. Кот поднимает голову и идёт на свет |
| 24–34 | Стрельчатая дверь с красным ромбом и табличкой TAINA. Дверь открывается, в тёплом свете — Маргарита. *Маргарита:* «Заходи, Бегемот. Теперь ты дома.» Кот входит, дверь закрывается |
| 34–37 | «Бегемот · Серия 1 · Дождь · Продолжение следует» |

## Серия 2 · «Дом для знаний»

| Время | Что происходит |
|---|---|
| 0–4 | Внутри: киностудия. Кинокамера, свет, хлопушка «TAINA · сцена 1», и горы документов, бумаги кружат в воздухе |
| 4–10 | *Бегемот:* «Это… киностудия?» *Маргарита:* «Студия. И дом для всего, что компании знают о себе.» |
| 11–17 | Кот садится у горы бумаг. *Бегемот:* «У твоих документов тоже нет дома. Они скитаются. Как я вчера.» |
| 17–22 | *Маргарита:* «Поможешь им?» *Бегемот:* «Я вижу больше.» — глаза вспыхивают |
| 22–29 | Из глаз кота — золотые нити. Документы взлетают и находят место на полках-арке; наверху загорается красный ромб |
| 29–34 | *Маргарита:* «Теперь у каждого документа есть дом.» *Бегемот:* «А у каждого ответа — адрес.» |
| 34–37 | «Серия 2 · Дом для знаний · Продолжение следует» |

## Серия 3 · «Первый гость»

| Время | Что происходит |
|---|---|
| 0–4 | Ночь, дождь за стрельчатым окном, полки светятся. Бегемот на столе. «Тук-тук.» |
| 4–11 | Входит промокший гость с зонтом и стопкой бумаг. *Гость:* «Мне сказали, здесь находят ответы.» *Маргарита:* «Спросите у Бегемота.» |
| 12–16 | *Гость:* «Какая схема приёма для повторных пациентов? Я неделю ищу…» |
| 16–21 | Глаза кота загораются, золотая нить тянется к нужной полке, документ слетает к гостю |
| 18–26 | Карточка ответа: вопрос → ответ → «Источник: Регламент приёма, п. 3.2». *Гость:* «Так это же наш регламент…» |
| 26–30 | *Бегемот:* «Ответ уже был у вас. Я просто знаю, где искать.» |
| 30–35 | Гость уходит. *Маргарита:* «Больше не скитаешься?» *Бегемот:* «Теперь я помогаю найти дорогу другим.» |
| 35–38 | «Серия 3 · Первый гость · Конец первой главы · Ответ уже есть. TAINA помогает его найти.» |

Пример в серии 3 демонстрационный (тот же, что на сайте). Клиентским кейсом его не называть.

## Подписи к публикациям

- **Серия 1.** В Петербурге дождь, и все двери закрыты. Почти все. #Бегемот
- **Серия 2.** Что делать, если у документов нет дома? Бегемот знает. #Бегемот
- **Серия 3.** Ответ уже был у вас. Бегемот просто знает, где искать. Ответ уже есть — TAINA помогает его найти.

## Сборка

`./build.sh` — рендер кадров (Playwright), звук (`sound.py`), MP4 в `out/`.
Отдельная серия: `EP=2 node render.mjs frames <папка> 30` и `python3 sound.py 2 out.wav`.
