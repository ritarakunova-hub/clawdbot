# Бренд TAINA

## Ядро

**«Ответ уже есть. TAINA помогает его найти».**

TAINA — не про ИИ как технологию, а про момент, когда бизнес обнаруживает:
ответ уже есть внутри компании, но сотрудники тратят часы, чтобы его
найти, проверить и передать.

## Файлы

- `storyboard.html` — раскадровка 30-секундного имиджевого ролика: 6 сцен
  с таймкодами, текстом на экране, звуком и промптами для генерации,
  общий стиль, ключевой арт, визуальная ДНК, шаги сборки. Открывается в
  браузере, промпты копируются кнопкой.

## Визуальная ДНК (коротко)

| Элемент | Значение |
|---|---|
| `#08080A` near black | неизвестность → шум → пространство для решения |
| `#D7A24C` золото | знание, найденный ответ (в начале мало, в конце много) |
| `#E8722E` янтарь | энергия, действие |
| Красный ромб | главный символ и источник света. **[ЗАПОЛНИТЬ] фирменный HEX**, пока временный `#C4302B` |
| Бумага, нити, архив → лабиринт | реальные знания бизнеса, связи документ → правило → ответ |
| Маленький человек без лица | проблема в объёме информации, а не в сотруднике |
| Кот Бегемот | редкая пасхалка, один раз, в спокойном кадре |

**Чего не бывает никогда:** роботы, голограммы, мозг из микросхем,
неон, мультяшные офисные работники, слоган «AI-решения для бизнеса».
